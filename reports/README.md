# SignBridge — Reports Directory

This directory contains output files generated by actual training and evaluation runs.
**Reports are not committed to source control and will not appear until you run the pipeline.**

## When reports appear

| File / Pattern | Created by | When |
|---|---|---|
| `dataset_summary.json` | `training.dataset_analysis` | After `run_pipeline_v1.bat` step 2 |
| `dataset_analysis.md` | `training.dataset_analysis` | After `run_pipeline_v1.bat` step 2 |
| `class_counts.csv` | `training.dataset_analysis` | After `run_pipeline_v1.bat` step 2 |
| `signer_counts.csv` | `training.dataset_analysis` | If dataset includes signer metadata |
| `evaluation_summary.json` | `training.evaluate` | After both models are trained |
| `evaluation.md` | `training.model_report` | After both models are trained |
| `baseline_confusion_matrix.png` | `training.plot_metrics` | After RF is trained |
| `lstm_confusion_matrix.png` | `training.plot_metrics` | After LSTM is trained |
| `model_accuracy.png` | `training.plot_metrics` | After at least one model is trained |
| `lstm_accuracy_curve.png` | `training.plot_metrics` | After LSTM is trained |
| `lstm_loss_curve.png` | `training.plot_metrics` | After LSTM is trained |
| `translation_comparison.md` | `training.compare_translation_models` | After V3 and V4 are trained |

## Running the pipeline

```powershell
# Quick smoke test (8 glosses, ~56 clips) — pipeline validation only
.\run_training_smoke.bat

# Full isolated-sign baseline (40 glosses, ~642 clips)
.\run_training_full_isolated.bat

# Sentence translation (requires paired continuous ISL data — see DATA_AND_LICENSE_NOTES.md)
.\run_translation_v3.bat
.\run_translation_v4.bat
```

## Interpreting results

- **Accuracy** is measured on the held-out test split produced during that run.
- When signer metadata is available and sufficient, the split is *signer-aware* (different
  signers in train and test). This is the only split that gives a fair estimate of
  generalisation to new signers.
- When signer metadata is absent or insufficient, a stratified random split is used and
  the `split_type` field in the metrics JSON will say so explicitly.
- BLEU and ROUGE scores for sentence translation are computed on the model's own test
  split and **do not represent performance on a separate benchmark**.
- Do not compare these metrics to published results without ensuring the same vocabulary,
  data source, split protocol and evaluation script are used.

## What is NOT in this directory

- Trained model weights (kept in `models/`)
- Raw video clips (kept in `data/raw/` and excluded from git)
- Landmark feature files (kept in `data/processed/` and excluded from git)
